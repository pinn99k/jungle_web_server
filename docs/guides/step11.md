# 스텝 11 읽기 가이드 — 백엔드 상황 스위치

## 1. 추가 · 변경 파일
| 파일 | 내용 |
|---|---|
| `backend/main.c` | `do_stats`(2초) · `apply_mode` · `now_ms` · `wait_ms`(막 켜진 상태면 10배) |
| `tests/traffic.sh` | 상황 번호를 주면 다시 재는 스크립트 (스텝 12) |

## 2. 함수 지도
| 함수 | 한 줄 설명 | 호출하는 곳 |
|---|---|---|
| `apply_mode` | "fail" · "cold=밀리초"를 스위치에 적용 | `main` |
| `do_stats` | 2초 뒤 통계 | `ROUTES` |
| `wait_ms` | 기다리기. 막 켜진 상태면 10배 | 각 경로 |

## 3. 순서
인자를 읽어 스위치를 정한다(시작할 때 한 번) → 그 뒤로는 읽기만 → 요청마다 `fail_mode`면 바로 500, 아니면 `route_request`

## 4. 추천 읽기 순서
`apply_mode` → `wait_ms` → `do_stats`

## 5. 실행해 볼 명령
```
./build/backend 8001 8 fail          # 모든 요청에 바로 500
./build/backend 8003 8 cold=5000     # 켜진 뒤 5초 동안 10배 느림
```
